# Quero Diarista

Sistema web completo para gestão de serviços de diaristas, com cadastro de profissionais, clientes, agendamento, pagamentos, avaliações e relatórios — tudo integrado ao Supabase com interface moderna em React.

## Funcionalidades
- Cadastro de diaristas e clientes
- Agendamento de serviços
- Processamento de pagamentos
- Avaliações e feedback
- Relatórios de desempenho

## Tecnologias
- Frontend: React, Vite
- Backend: Supabase (PostgREST, Auth, Storage)
- Deploy: Vercel

## Como começar
```bash
# Clone o repositório
git clone https://github.com/Luanlessa31/Quero-Diarista.git
cd Quero-Diarista
# Instale as dependências
npm install
# Inicie o projeto
npm run dev
```
